# 🚛 DP World Route Optimization Dashboard

A logistics analytics and route optimization project developed to improve transportation efficiency for container deliveries. The solution combines Python-based route optimization techniques with Power BI visualizations to identify optimal delivery sequences, reduce travel distance, and uncover potential cost savings.

## 📌 Project Overview

This project focuses on optimizing container transportation routes from the DP World hub using route planning algorithms and business intelligence tools.

By analyzing delivery locations, travel distances, container volumes, and operational constraints, the solution generates optimized routes and presents actionable insights through an interactive dashboard.

## 🎯 Objectives

* Optimize delivery routes for container transportation
* Reduce unnecessary travel distance
* Improve transportation efficiency
* Identify fuel and operational cost savings
* Visualize logistics performance using Power BI
* Support data-driven decision making
